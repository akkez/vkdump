# VKdump

Parse and export VK chat archives.

## Install on macOS

```sh
brew tap akkez/vkdump https://github.com/akkez/vkdump
brew install --cask akkez/vkdump/vkdump
```

The cask installs `VKdump.app` and removes quarantine recursively.

## Windows / Linux

Download from [Releases](https://github.com/akkez/vkdump/releases), extract the entire archive, and run `vkdump-gui` (`vkdump-gui.exe` on Windows). Keep `_internal` beside the executables. CLI: `vkdump --help`.
