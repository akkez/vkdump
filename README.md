# VKdump

Parse and export VK chat archives.

## Install on macOS

```sh
brew tap akkez/vkdump https://github.com/akkez/vkdump
brew install --cask akkez/vkdump/vkdump

# Open UI
open -a /Applications/VKdump.app

# CLI
/Applications/VKdump.app/Contents/MacOS/vkdump-cli --help
```

## Windows / Linux

Download from [Releases](https://github.com/akkez/vkdump/releases), extract, and run `vkdump` (`vkdump.exe` on Windows). CLI: `vkdump-cli --help`.
